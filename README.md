# 🐱 Zyaper

Привет! Это **Zyaper** — мой личный пет-проект, который я сделал, чтобы больше никогда в жизни не переслушивать часовые созвоны ради пары важных фраз.

Программа просто берёт твой аудио- или видеофайл, локально (без интернета!) распознаёт русскую речь и выдаёт готовый текст. 

> *Сейчас это первая версия (v1.0). Всё работает, но я продолжаю пилить новые фичи.*

---

## ✨ Что оно умеет прямо сейчас?

* 🎧 **Жуёт всё подряд:** Поддерживает популярные форматы (`mp4`, `mkv`, `avi`, `mp3`, `wav`).
* 🗣️ **Понимает по-русски:** Внутри крутится модель `faster-whisper` (medium), которая неплохо справляется с нашей речью.
* 💾 **Даёт сохранить:** Готовый текст можно экспортировать в `.txt` или `.md`.
* 🎨 **Выглядит мило:** Светлая тема и зелёный котик-инопланетянин на иконке.
* 📴 **Работает без сети:** Всё считается на твоём железе. Никакие данные никуда не улетают.

---

## 🚀 Как это запустить?

Приложение распространяется в виде **портативной версии** (ZIP-архив). Никаких установщиков и ярлыков, всё по-спартански.

1. Иди в раздел **[Releases](https://github.com/LXMinus/ZYAPER/releases)**.
2. Скачай архив `Zyaper_v1.0.0_Portable.zip`.
3. Распакуй его в любую папку (хоть на рабочий стол).
4. Запускай `Zyaper.exe`.

> ⚠️ **Важно (читать глазами):** Не надо запускать `.exe` прямо из окна архиватора! Windows не любит такое, и программа не найдёт свои внутренние файлы. Обязательно **сначала извлеки** всё из архива.

## 💡 Лайфхак: как достать задачи, пока нет встроенной LLM

Сейчас Zyaper умеет делать только транскрипт. Встроенный анализ договорённостей я вырезал и сейчас работаю над его нормальной версией. 

Но если тебе **прямо сейчас** нужно вытащить задачи и решения из текста — просто скопируй транскрипт в **DeepSeek** (или любую другую LLM) и добавь этот промпт:

```text
Ты — опытный ассистент менеджера. Твоя задача — проанализировать ТЕКСТ ВСТРЕЧИ, который приведен в самом конце, и выделить из него задачи и решения.

ПРАВИЛА:
1. Задача — это любое действие, которое кто-то должен выполнить (даже если это сказано в форме "надо сделать").
2. Если в тексте названо имя или человек говорит от первого лица ("я сделаю") — укажи его в поле assignee. Иначе null.
3. Срок ставь только если явно названа дата ("до пятницы", "во вторник"). Иначе null.
4. Решение — это согласованный вывод ("решили использовать EXCEL"). Не дублируй решения в задачах.

ФОРМАТ ОТВЕТА (строго JSON):
{
  "tasks": [
    {"description": "полное описание задачи", "assignee": "имя или null", "deadline": "срок или null", "is_priority": false}
  ],
  "decisions": ["решение 1", "решение 2"],
  "summary": "краткое резюме встречи"
}
